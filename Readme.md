#  E-Commerce Sales & Customer Behavior Analytics

An end-to-end data analytics project examining retail transaction data to uncover revenue drivers, profit margins, and customer retention insights using SQL, Python, and Power BI.

##  Key Highlights & Insights
- RFM Customer Segmentation : Categorized customers into VIP, Loyal, and Risk-of-Churn segments using Recency, Frequency, and Monetary scores.
- Profitability Analysis: Identified key loss-making product categories and analyzed discount thresholds affecting net profit.
- Regional Performance: Dynamic sales distribution and order volume trends across geographical regions.

##  Tech Stack
- SQL: Data extraction, joins, GROUP BY aggregations, and window functions.
- Python (Pandas, NumPy): Data cleaning, missing value handling, and exploratory data analysis.
- Power BI: Interactive KPI cards, cross-filtering charts, and dynamic slicers.
